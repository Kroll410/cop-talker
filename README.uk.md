# StalkerTalker

Живі розмови з NPC у **S.T.A.L.K.E.R.: Поклик Прип'яті**: тримаєш **T**, говориш українською в мікрофон, сталкери
відповідають голосами з гри (клони ElevenLabs), пам'ятають тебе, жартують, торгуються, беруть замовлення,
йдуть за тобою, сваряться між собою. Опційно: повідомлення з Twitch-чату озвучують NPC.

## Що потрібно

- **S.T.A.L.K.E.R.: Call of Pripyat** (GOG або Steam, версія 1.6.02).
- **OpenXRay** — сучасний рушій гри, без нього мод не працює:
  https://github.com/OpenXRay/xray-16/wiki/%5BEN%5D-How-to-install-and-play
- **Українська озвучка** гри (пакет з `xukrainian.db`) — з неї робляться зразки голосів.
- **Python 3.13** (підходять 3.10–3.13; новіші поки ні) — https://www.python.org/downloads/
  (при встановленні постав галочку *Add python.exe to PATH*).
- Мікрофон, інтернет, Windows 10/11.

## Встановлення

1. Розпакуй архів у будь-яку папку (наприклад `C:\StalkerTalker`).
2. Запусти **`setup.bat`**. Він сам:
   - поставить потрібні бібліотеки (кілька хвилин першого разу),
   - спитає папку гри,
   - встановить мод у гру,
   - створить файл ключів `.env` і відкриє його,
   - зробить ярлик **StalkerTalker** на робочому столі,
   - запропонує зробити зразки голосів для клонування.
3. Впиши ключі в `.env` (див. нижче) і збережи.

## Ключі (`.env`)

- **GEMINI_API_KEY** — безкоштовно: https://aistudio.google.com/apikey . Це «мізки» NPC і розпізнавання мови.
- **ELEVENLABS_API_KEY** — https://elevenlabs.io → Developers → API Keys. Для клонування голосів потрібен план
  **Starter** (~5$/міс). Дай ключу доступ до Text to Speech (і бажано Voices Read, User Read — тоді видно залишок
  кредитів).
- **VOICE_...** — ID клонованих голосів (наступний розділ).

`.env` — твій особистий файл. Нікому його не пересилай.

## Голоси

1. Після `setup.bat` у папці `samples` лежать зразки: `human_01_ukr.mp3`, `human_02_ukr.mp3`, `human_03_ukr.mp3`
   (якщо пропустив — запусти ще раз `setup.bat`). Фракційні (бандити, «Свобода», військові) — у `samples\factions`.
   Якщо setup не знайшов `xukrainian.db` (лежить поза папкою гри), зроби зразки вручну в папці StalkerTalker:
   `.venv\Scripts\python.exe tools\make_voice_samples.py "шлях\до\xukrainian.db" samples`
2. На ElevenLabs: **Voices → Add a new voice → Instant Voice Clone**, завантаж один зразок, назви голос.
3. Скопіюй **Voice ID** у `.env`: `human_01` → `VOICE_HUMAN_01`, і так далі.
   Мінімум — три основні голоси; решта необов'язкові (без них беруться основні).

## Гра

1. Запусти гру, потім **StalkerTalker** з робочого столу (вікно з журналом і налаштуваннями).
2. Біля сталкера **тримай T** і говори. Внизу екрана «Слухаю...», потім «Думає...», потім відповідь голосом.
3. **Y** — сталкер іде за тобою, **U** — лишається (клавіші: `gamedata\configs\scripts\talker.ltx` у папці гри).
4. Можна: питати дорогу і плітки, торгуватися («Продай аптечку», «Дам 500 за горілку»), замовити вбивство за гроші,
   звертатися до всіх («Пацани, ...»), лікувати поранених — запам'ятають.

## Налаштування

У вікні StalkerTalker → вкладка **Settings** (кнопка *Save and restart*). Найцікавіше:

- **FUN_LEVEL** — `normal`, `high`, `max`: скільки жартів і мату.
- **SPEAK_MODE** — `all` або `chat` (говорять лише повідомлення з Twitch).
- **MIC** — `auto` бере мікрофон ноутбука, щоб Bluetooth-навушники не перемикались у «режим дзвінка»
  (тоді звук стає поганим); можна вписати частину назви свого мікрофона.
- **SUBTITLES** — `bottom`, `pda`, `both`.

## Twitch (необов'язково)

1. https://dev.twitch.tv/console/apps → Register Your Application: OAuth Redirect URL `http://localhost`,
   Category *Game Integration*, Client Type **Public**.
2. Client ID → у `.env` як `TWITCH_CLIENT_ID=...`, у Settings → `TWITCH_CHANNEL` = твій канал.
3. У вікні: вкладка **Twitch → Authorize Twitch app**.
4. У чаті: `$текст` — NPC скаже слово в слово, `%текст` — перекаже по-своєму. Решту чату ігнорує.

## Якщо щось не так

- Журнал: вкладка **Log** у вікні, файл `logs\stalkertalker.log`.
- Помилки з боку гри: `talker\bridge_errors.log` у папці гри.
- Після оновлення моду: **завантаж збереження** (гра перечитує скрипти).
- Видалити мод із гри: `uninstall_mod.ps1` (правою кнопкою → Run with PowerShell).
