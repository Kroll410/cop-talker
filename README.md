# cop-talker

Живі голосові розмови з NPC у **S.T.A.L.K.E.R.: Поклик Прип'яті** (OpenXRay). Тримаєш **T**, говориш українською, і сталкер, на якого дивишся, відповідає вголос голосом із гри.

English: [README.en.md](README.en.md)

## Що вміє

- **Розмова.** Push-to-talk до NPC перед тобою. Він відповідає у своєму характері (фракція, ранг, настрій, поранення, погода, викид) і пам'ятає тебе між сесіями.
- **NPC самі по собі.** Вітання, репліки, реакції (підібраний артефакт, аномалія, клин зброї), балачки компаньйона, розмови NPC між собою. Говорять і про життя поза Зоною та справжні свіжі новини України й світу.
- **Дії з розмови.** Жести, «іди за мною» / «стій», ворожість, дружба, купівля й продаж речей, передача грошей, замовні вбивства. Замовлення працює на ціль будь-де на локації: загін кілера йде полювати на загін цілі.
- **Twitch (необов'язково).** Повідомлення з `$` (слово в слово) або `%` (переказ своїми словами) озвучують NPC поруч. Кожен глядач прив'язаний до одного NPC; якщо дивишся на нього, видно `Ім'я [нік]`.
- **Вікно.** Журнал, налаштування, вхід у Twitch, лічильник використання.

## Як працює

```
гра (Lua, talker_bridge.script)  <-- файли в <гра>\talker\ -->  помічник (Python, companion\)
  state.json   NPC поруч, гравець, локація, товар     -> читається кожні 0,5 с
  events.jsonl смерті, влучання, знахідки, клавіші    -> читається кожні 0,3 с
  inbox.txt    репліки, субтитри, дії                 <- пише помічник
```

Помічник:
1. розпізнає мову;
2. питає LLM про відповідь і дії;
3. озвучує її в ElevenLabs;
4. відтворює з об'ємним звуком і гучністю за відстанню.

Скрипт гри показує субтитри, рухає роту NPC і виконує дії.

## Що потрібно

- S.T.A.L.K.E.R.: Call of Pripyat 1.6.02 (GOG або Steam) з **OpenXRay**: [інструкція](https://github.com/OpenXRay/xray-16/wiki/%5BEN%5D-How-to-install-and-play)
- Українська озвучка (`xukrainian.db`): лише щоб зробити зразки голосів
- Windows 10/11, Python **3.10–3.13** (галочка «Add python.exe to PATH»)
- Ключ Gemini (безкоштовний) та/або підписка Claude з [Claude Code](https://claude.com/claude-code)
- Акаунт ElevenLabs із клонуванням голосу (план Starter)

## Встановлення

1. Завантаж або склонуй репозиторій у будь-яку папку.
2. Запусти **`setup.bat`**. Він:
   - ставить бібліотеки Python у `.venv`;
   - питає папку гри;
   - копіює `mod\` у `<гра>\gamedata`;
   - створює `.env` з `.env.example`;
   - робить ярлик на робочому столі;
   - пропонує нарізати зразки голосів у `samples\`.
3. Впиши ключі в **`.env`**:
   - `GEMINI_API_KEY`: з https://aistudio.google.com/apikey
   - `ELEVENLABS_API_KEY`
   - `VOICE_HUMAN_01..03` (обов'язкові): в ElevenLabs зроби клон із кожного `samples\human_0N_ukr.mp3` (Voices → Instant Voice Clone) і встав його Voice ID.
   - Голоси фракцій (`VOICE_*_BANDIT`, `VOICE_FREEDOM_*`, …): за бажанням.
4. Щоб замість Gemini був Claude:
   - встанови Claude Code;
   - один раз запусти `claude` і введи `/login`;
   - у `settings.ini` постав `LLM_PROVIDER=claude`.
5. Запусти гру, завантаж збереження, потім відкрий **StalkerTalker** з робочого столу.

## Керування

| Клавіша | Дія |
|---|---|
| **T** (тримати) | говорити з NPC, на якого дивишся |
| **Y** | NPC іде за тобою |
| **U** | NPC лишається |

Клавіші змінюються в `gamedata\configs\scripts\talker.ltx` у папці гри.

- **Налаштування:** вкладка Settings у вікні змінює `settings.ini`.
- **Twitch:**
  1. Створи застосунок на https://dev.twitch.tv/console/apps (Client Type: Public).
  2. Його ID впиши в `.env` як `TWITCH_CLIENT_ID`.
  3. У `settings.ini` впиши `TWITCH_CHANNEL`.
  4. У вікні: Twitch → *Authorize Twitch app*.

## Оновлення та видалення

- Після змін у `mod\` запусти `install_mod.ps1`, потім **завантаж збереження**: гра перечитує скрипти лише тоді. Помічник попередить, якщо гра працює зі старим скриптом.
- Видалити мод із гри: `uninstall_mod.ps1`.

## Що лишається тільки в тебе
